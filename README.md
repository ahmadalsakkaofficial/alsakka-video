# alsakka-video

Claude Code plugin that turns a raw Arabic talking-head video into a **finished reel MP4** (macOS, no editing app needed): cuts and silence removal, word-timed Arabic captions, a written hook, motion-graphics scenes, punch-ins, transitions and subtle SFX. Optional: the same edit as an editable CapCut timeline.

- Install: `/plugin marketplace add ahmadalsakka1994/alsakka-video` then `/plugin install alsakka-video@alsakka`, then tell Claude «جهّز البلجن».
- Use: drop the video into the chat and tell Claude «منتجلي هالفيديو».
- Guide (Arabic): [دليل_الاستخدام.md](دليل_الاستخدام.md)

Built on ideas and parts of [majed-video](https://github.com/majedphotos/video-ad-editor) by Majed Alzaabi (MIT) — thank you.
